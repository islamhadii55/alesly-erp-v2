# تطبيق أندرويد — الأصلي لقطع الغيار

تطبيق WebView يشغّل نظام ERP نفسه، ويتصل بسيرفر المحل (جهاز الكمبيوتر) عبر الشبكة المحلية أو الإنترنت.
يعمل التطبيق مع كاش Service Worker، فعند انقطاع الاتصال تُحفظ العمليات محلياً وتُزامَن تلقائياً عند عودة الشبكة.

## المتطلبات
- Android Studio (Ladybug أو أحدث)
- Java 17

## خطوات البناء
1. افتح مجلد `android/` في Android Studio.
2. انتظر Gradle Sync (سيُنزّل توزيعة Gradle تلقائياً).
3. من القائمة: Build > Build Bundle(s)/APK(s) > Build APK(s).

## ضبط عنوان السيرفر
- الافتراضي: `http://10.0.2.2:5000` (يعمل على محاكي أندرويد حيث 10.0.2.2 = جهاز التطوير).
- على جهاز حقيقي: اضغط ضغطة مطوّلة على الشاشة، أدخل عنوان الكمبيوتر على الشبكة المحلية مثل `http://192.168.1.10:5000`.
- للاستخدام عبر الإنترنت: ضع رابط الاستضافة الخاص بالنظام.

## تشغيل سيرفر سطح المكتب
```bash
python3 app.py
```
ثم اجعل المنفذ 5000 متاحاً على الشبكة المحلية، أو استخدم رابط الاستضافة.
